# Skyware Landing

Aplicacion web de Skyware creada con React, Vite y Tailwind CSS.

## Uso local

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Donde editar

- Configuracion de marca y contacto: `src/config/site.js`
- SEO: `src/config/seo.js`
- Contenido editable: `src/data/`
- Componentes de secciones: `src/components/sections/`
- Estilos globales: `src/styles/globals.css`
